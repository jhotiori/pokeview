# 🔍️ POKEVIEW
> **A small application originally made as an University Project. PokeView aims on integrating Soft and Hard Skills into a software application, applying several concepts alongside team-work. While the main goal was just delivering it, we decided to do more - this is where the optimization strategies, documentation and padronization came into play.**

## 📦️ INSTALLATION
> **PokeView uses [**Bun**](https://bun.sh/) as it's package manager. Ensure to have bun installed before continuing!**

Clone this repository:
```bash
git clone https://github.com/jhotiori/pokeview
```

Navigate into the cloned project:
```bash
cd pokeview
```

Run the **`check`** command to install all dependencies and format code:
```bash
bun run check
```

Then, decide whether to run the **`dev`** command to start the development server:
```bash
bun run dev
```
> Then check-out **`http://localhost:8000`** in your browser.

Or the **`build`** command to build the production version and visualize it:

```bash
bun run build
```
> Then check-out **`http://localhost:8001`** in your browser.
